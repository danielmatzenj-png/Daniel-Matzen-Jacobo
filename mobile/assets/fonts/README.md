# Fonts

Place these `.ttf` files in this folder before running the app:

- `Anton-Regular.ttf` — Display headings (download: https://fonts.google.com/specimen/Anton)
- `Inter-Regular.ttf` — Body text (download: https://fonts.google.com/specimen/Inter)
- `Inter-Bold.ttf` — Body bold
- `SpaceMono-Regular.ttf` — Countdowns / mono (download: https://fonts.google.com/specimen/Space+Mono)

All four are free under SIL Open Font License.

## Quick install

```bash
# from the project root
mkdir -p mobile/assets/fonts
curl -L "https://github.com/google/fonts/raw/main/ofl/anton/Anton-Regular.ttf" -o mobile/assets/fonts/Anton-Regular.ttf
curl -L "https://github.com/rsms/inter/raw/master/docs/font-files/Inter-Regular.otf" -o mobile/assets/fonts/Inter-Regular.ttf
curl -L "https://github.com/rsms/inter/raw/master/docs/font-files/Inter-Bold.otf" -o mobile/assets/fonts/Inter-Bold.ttf
curl -L "https://github.com/google/fonts/raw/main/ofl/spacemono/SpaceMono-Regular.ttf" -o mobile/assets/fonts/SpaceMono-Regular.ttf
```
