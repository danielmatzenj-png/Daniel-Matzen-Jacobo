# Assets

Required image assets (add before building for stores):

- `icon.png` — 1024×1024 app icon (Dared logo on `#0A0A0F` background)
- `adaptive-icon.png` — 1024×1024 Android adaptive foreground
- `splash.png` — 1284×2778 splash screen image

For local development, Expo will use defaults if these are missing. Generate
production assets with the brand colors:
- Background: `#0A0A0F`
- Logo color: `#FFFFFF` with `#FF2D55` slash accent
